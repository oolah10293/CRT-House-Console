# Changelog

## v0.3.3 — field baseline (original release 2026-10-04)

- Working Wi-Fi reconnection after v0.3.2 join regression (user-confirmed).
- Eight-page CRT console, including Track Queue as second page, live-only House Nodes, House Health, House Systems, clock, microphone-driven visualizer and CRT Test.
- Manual and six-second auto-cycle page navigation.
- V0.3.3 behavior preserved; private LAN addresses replaced with documentation-only addresses for the public repository.
- **Known outstanding regression:** repeated JSON buffer allocation failure during later runtime, surfaced 2026-10-09.

## Repository initialization

- Imported v0.3.3 and sanitized local network addresses; no runtime code fixes.
- Documented confirmed bugs, suspected causes and acceptance criteria.
